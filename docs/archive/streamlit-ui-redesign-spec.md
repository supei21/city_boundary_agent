> **归档说明**：这是旧版 Streamlit UI 的历史设计记录，不代表当前 React + FastAPI 界面。当前项目入口与目录请以根目录 `README.md` 为准。

**日期**: 2026-08-09  
**状态**: 已确认  
**目标**: 将 Streamlit 三列固定布局重构为现代 AI 智能体对话界面

---

## 1. 概述

### 当前状态

- 布局：左侧边栏 (310px) + 中间对话栏 (1.55fr) + 右侧预览栏 (1fr)
- 左侧边栏始终可见，包含数据上传、SHP 分析、批量分析、文件列表、状态
- 中间为自建聊天表单（text_area + submit button）
- 右侧固定显示文件预览（属性表 / pydeck 地图 / JSON）
- 视觉风格：大地暖色调 (beige, 棕色, 米色背景)

### 目标状态

- **左侧**：可折叠功能区 (展开 260px / 折叠 48px)，VS Code 风格
- **中间**：聊天主视口，底部固定输入框，类 ChatGPT 对话体验
- **右侧**：滑入式抽屉预览面板 (隐藏/滑入)，带遮罩层，420px 宽
- **视觉**：现代 AI 风格，白灰极简 + 蓝/绿强调色

### 技术方案

方案 A: Streamlit + CSS/JS 增强（纯 Python，无额外构建依赖）

├────────┬─────────────────────────────────────┬────────────┤

### 面板叠加关系 (z-index)

1. 背景层：对话主视口 (z-index: 0)

3. 遮罩层：右侧抽屉遮罩 (z-index: 999)
4. 抽屉层：右侧预览面板 (z-index: 1000)

- 窗口宽度 < 768px 时：左侧栏自动折叠，右侧抽屉全屏展开
- 1024px+ 时：完整三面板布局

## 3. 左侧栏设计

### 展开态 (260px)

```
┌─────────────────────────┐
│ 功能区            [✕ ←] │
├─────────────────────────┤
│ 📂 数据源               │
│  ○ 内置示例  ● 上传文件  │
│  [拖拽上传区域]          │
│  当前街区: N 个          │
├─────────────────────────┤
│ 🗺️ SHP 空间分析         │
│  [上传空间文件]          │
│  [上传并输出SHP]         │
├─────────────────────────┤
│ 📊 批量分析              │
│  [批量分析属性数据]       │
├─────────────────────────┤
│ 📁 输出文件              │
│  (按时间排列的文件列表)   │
├─────────────────────────┤
│ ⚙️ 模型状态              │
│  ● 模型就绪 / ○ 未启用   │
│─────────────────────────│
│ [清空全部任务]           │
└─────────────────────────┘
```

### 折叠态 (48px)

仅显示图标列，hover 时 tooltip 提示功能名称：

```
┌────┐
│ ☰ │  ← 展开按钮
│ 📂│  ← 数据源
│ 🗺│  ← SHP分析
│ 📊│  ← 批量分析
│ 📁│  ← 输出文件
│ ⚙│  ← 状态
│ 🗑│  ← 清空
└────┘
```

### 交互规则

- 顶部 ☰ hamburger 按钮切换折叠/展开
- 快捷键 `Ctrl+B` 切换
- 折叠态 hover 图标时浮出 tooltip
- CSS `transition: width 0.25s ease`
- 状态存储 `st.session_state.sidebar_collapsed`

### 实现方式

Streamlit `st.sidebar` + CSS class 切换。折叠时通过 `display: none` 隐藏文字内容，仅保留图标。

## 4. 中间对话区设计

### 整体结构

```
┌─────────────────────────────────────┐
│ 🏙️ 城镇开发边界智能体               │
│ 对话分析 · 空间处理 · 结果追踪       │
├─────────────────────────────────────┤
│                                     │
│  消息列表（可滚动）                  │
│  - 智能体消息 (左对齐, 白底灰框)     │
│  - 用户消息 (右对齐, 浅蓝底)         │
│  - 内嵌数据表/卡片                  │
│  - 消息操作按钮                     │
│                                     │
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐   │
│  │ 输入你的问题...         📎  ▶│   │
│  └─────────────────────────────┘   │
│  [快速查看] [分析候选] [调入调出]    │
└─────────────────────────────────────┘
```

### 输入区域

- 使用 `st.chat_input(placeholder="输入你的问题...")`
- 固定在聊天区底部
- 圆角边框 `border-radius: 16px`
- 聚焦时蓝色发光效果 (`box-shadow: 0 0 0 3px rgba(59,130,246,0.3)`)
- 输入框下方一行快捷提示 pill 标签

### 快捷提示 (Quick Prompts)

灰色圆角标签，点击后自动填入输入框：
- "查看全部街区数据"
- "哪些街区适合调入开发边界？"
- "找出建议调出的边界内街区"
- "分析 [block_id] 的适宜性"

### 消息气泡

| 角色 | 外观 | 位置 |
|------|------|------|
| 用户 | 浅蓝底 `#eff6ff`，蓝灰边框 | 右对齐 (max-width: 75%) |
| 智能体 | 白底 `#fff`，灰色边框，轻微阴影 | 左对齐 (max-width: 80%) |

- 圆角 `border-radius: 12px`
- 内边距 `padding: 12px 16px`
- 顶部小字角色标签 (用户="你" / 智能体="🏙️ 智能体")
- 智能体消息底部可折叠 "查看分析过程 ›" 展开 ReAct 工具调用链

### 思考状态

等待模型回复时，显示跳动动画：
```
●●● 正在分析...
```
三个圆点依次缩放/淡入淡出，CSS animation。

### 实现方式

- 使用 `st.chat_message()` 渲染消息
- 使用 `st.chat_input()` 获取用户输入
- 消息列表存 `st.session_state.chat_messages`
- 快捷提示用 `st.pills()` (Streamlit 1.41+)
- JavaScript 自动滚动到底部

## 5. 右侧预览设计

### 抽屉机制

- 默认隐藏: `transform: translateX(100%)`
- 打开时滑入: `transform: translateX(0)`
- `transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- 宽度: 420px
- 半透明遮罩覆盖聊天区: `rgba(0, 0, 0, 0.3)`
- 点击遮罩关闭
- 按 `Esc` 键关闭
- 状态: `st.session_state.drawer_open`, `st.session_state.drawer_artifact_id`

### 抽屉内容

```
┌──────────────────────────┐
│ 📄 decisions.json    [✕] │  ← 标题栏
│ JSON · 14:25:30          │
├──────────────────────────┤
│                          │
│  ┌────────────────────┐  │
│  │ block_id  │ 决策   │  │  ← 属性表 (st.dataframe)
│  ├───────────┼────────┤  │
│  │ WH2025_001│ 调入   │  │
│  │ WH2025_002│ 保留   │  │
│  │ ...       │ ...    │  │
│  └────────────────────┘  │
│                          │
│  🗺️ 地图预览 (SHP 文件)  │  ← pydeck 地图 (st.pydeck_chart)
│  ┌────────────────────┐  │
│  │    [地图图层]       │  │
│  └────────────────────┘  │
│                          │
│  JSON 原始数据 (JSON)    │  ← st.json
│  { ... }                 │
│                          │
├──────────────────────────┤
│  [📥 下载]  [🔗 复制链接] │  ← 操作栏
└──────────────────────────┘
```

### 文件切换

- 抽屉同一时间只显示一个文件
- 点击新文件预览 → 直接替换当前预览内容
- 后续可扩展为多 tab 模式

### 与消息联动

- 聊天消息中点击 "加入预览" → 自动打开抽屉显示对应文件
- 行为: `on_click` → `session_state.drawer_open = True; drawer_artifact_id = artifact_id`

### 实现方式

- 抽屉内容区域用 `st.container()` + CSS 固定定位
- 遮罩用 `<div class="drawer-overlay">` + JavaScript 处理点击
- `st.components.html` 注入 JS 处理 Esc 键和遮罩点击

## 6. CSS/JS 注入策略

### CSS

全部通过 `st.markdown(<style>, unsafe_allow_html=True)` 在 `setup_page()` 中注入：

- 使用 `[data-testid="..."]` 选择器定位 Streamlit 组件
- 使用 `!important` 覆盖 Streamlit 默认样式
- 侧栏折叠 class: `[data-testid="stSidebar"]` + CSS transition
- 保留回退样式：如果选择器失效，回退到当前暖色方案

### JavaScript

通过 `st.components.html(<script>, height=0)` 注入：

```js
// 核心功能
1. 遮罩点击 → 发送 postMessage 给 Streamlit → 设置 drawer_open=False
2. Esc 键 → 关闭抽屉
3. 消息列表自动滚动到底部 (MutationObserver)
4. 折叠态侧栏 tooltip 管理
```

### 兼容性

- 主要 DOM 选择器基于 Streamlit 1.41+ `data-testid` attribute
- 如果 Streamlit 升级改变了 DOM，样式会降级但功能完好
- 降级表现：侧栏不变、右栏变为固定列

## 7. 状态管理

### 现有 session_state keys (不变)

| Key | 用途 |
|-----|------|
| `chat_messages` | 对话历史 `[{role, content}]` |
| `artifacts` | 输出文件列表 |
| `selected_artifact` | 当前选中的文件 ID |

### 新增 session_state keys

| Key | 类型 | 默认值 | 用途 |
|-----|------|--------|------|
| `sidebar_collapsed` | bool | False | 左侧栏折叠状态 |
| `drawer_open` | bool | False | 右侧抽屉开/关 |
| `drawer_artifact_id` | str | None | 抽屉中预览的文件 ID |

### 数据流

```
用户点击预览
  → session_state.drawer_open = True
  → session_state.drawer_artifact_id = artifact_id
  → st.rerun()
  → 渲染抽屉（根据 drawer_artifact_id 查找 artifact）

用户点击遮罩 / Esc
  → session_state.drawer_open = False
  → st.rerun()
  → 抽屉关闭
```
